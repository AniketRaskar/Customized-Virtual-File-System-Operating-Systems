I developed a customized Virtual File System in C++ to simulate Linux-style file management. I implemented core structures such as the Superblock, Inode, Disk Inode List Block, User File Descriptor Table, and File Table.

The system provides a custom command-line shell where users can create, open, read, write, delete, and truncate files, as well as change file offsets using lseek.

I also implemented inode allocation, file permissions, metadata handling, and reference counting. This project helped me understand how operating systems manage files internally.
